# Open-Meteo Weather & Air Quality Dashboard

A responsive web application built with Vanilla JavaScript, HTML, and CSS for the Code the Dream Pre-Work Assignment.

##  Features

- Endpoint 1 (Weather Forecast):Displays current temperature, relative humidity, wind speed, and a 7-day high/low temperature table fetched from Open-Meteo's `/v1/forecast` endpoint.
- Endpoint 2 (Air Quality):Displays live pollutant counts (PM2.5, PM10, CO, NO₂) and US AQI index from Open-Meteo's endpoint.
- Dynamic Single-Page Navigation: Switch views seamlessly without full page reloads or redundant data calls.
- Error & Loading Feedback: Provides visible feedback when loading data or handling network issues.
